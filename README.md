# Smart-Battery-Management-System-BMS-for-3S-Li-Po-Battery
Designed a 3S Li-Po Smart BMS PCB using ESP32-S3 and BQ76920. Integrated cell-voltage and current monitoring, NTC temperature sensing, MOSFET-based charge/discharge protection, power regulation, heater control, USB-C, OLED and UART interfaces. Developed the complete schematic, PCB layout, routing and 3D design in KiCad.
